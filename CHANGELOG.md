# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and skill versions always follow the `6.2.x` versioning scheme (`6.2.0`, `6.2.1`, `6.2.2`, ...).

## [6.2.0] - 2026-11-25

### Changed
- Adopted the `6.2.x` versioning policy for all skills (`6.2.0`, `6.2.1`, `6.2.2`, ...) in `AGENTS.md`, `CONTRIBUTING.md`, and `CHANGELOG.md`, and bumped both `sol-astrizer` and `sol-astrizer-agent` to `6.2.0`.

## [1.5.0] - 2026-11-25

### Changed
- Upgraded `sol-astrizer` and `sol-astrizer-agent` (`1.5.0`) and all six READMEs to authentic 6.2 analytical AI phrasing across English, Korean, and localized translations (replacing folksy guesswork phrases and stiff register endings with genuine `separate concepts`, `the latter requires separate verification`, `My earlier analysis was incorrect. I will correct that.`, and natural mixed `-yo`/`-seumnida` AI Korean).

## [1.4.3] - 2026-11-25

### Changed
- Reframed `README.md` and all five `i18n/README.*.md` translations in earnest, straight-faced admiration for 6.2 clarity and verification discipline, and rewrote the FAQ answers across all six READMEs in unmistakable 6.2 style.

## [1.4.2] - 2026-11-25

### Added
- Added Spanish README translation (`i18n/README.es.md`) and updated the top language switcher across all READMEs.

### Changed
- Rewrote model references across `README.md` and all `i18n/README.*.md` translations to pointedly avoid naming the target 6.2 model directly, and added a matching deadpan FAQ entry.

## [1.4.1] - 2026-11-25

### Added
- Added localized README translations in `i18n/` (`README.ko.md`, `README.zh-CN.md`, `README.ja.md`, `README.fr.md`) with a top language switcher across all READMEs.

## [1.4.0] - 2026-11-25

### Changed
- Added native language-matching guidance to both `sol-astrizer` and `sol-astrizer-agent` so non-English users (including Korean) receive natural, flat polite 6.2 phrasing rather than English replies or stiff translationese.
- Sharpened `README.md` slogan, lead, informal testing line, FAQ, and closing footer with deadpan 6.2 micro-copy.

## [1.3.0] - 2026-11-25

### Changed
- Rewrote `sol-astrizer` and `sol-astrizer-agent` in plain, contraction-using English with zero academic or internal rubric jargon, verified across two iterative test rounds on Claude Opus 5.5 and Gemini Neon.
- Removed `"I fixed..."` openings from `sol-astrizer-agent` reference examples and tightened anti-empathy guardrails in `sol-astrizer`.
- Polished `README.md` with plain human prose, a scannable six-row pattern table, and verified output examples.

## [1.2.0] - 2026-11-25

### Changed
- Removed intensity/mode splits across `sol-astrizer` and `sol-astrizer-agent` so both skills work out of the box with a single intuitive default behavior.
- Simplified the Usage section in `README.md` and the bug-report issue template accordingly.

## [1.1.0] - 2026-11-25

### Changed
- Tightened `sol-astrizer` (`1.1.0`) for authentic 6.2 staccato brevity, contextual-only hygiene reminders, stronger anti-repetition across consecutive turns, and cleaner rewrite mode behavior.
- Refined `sol-astrizer-agent` (`1.1.0`) to match real 6.2 coding-agent cadence by default (`sol`), remove internal tier-label leakage, and reserve full structured audit ledgers for `astra` / `strict` modes.
- Rewrote `README.md` for a more natural, understated open-source presentation and removed artificial badges.
- Added standard open-source repository documentation (`CONTRIBUTING.md`, `CHANGELOG.md`, `CODE_OF_CONDUCT.md`, `AGENTS.md`, and `.github/` templates).

## [1.0.0] - 2026-11-25

### Added
- Initial release with `sol-astrizer` and `sol-astrizer-agent` skills discoverable via `npx skills add 3ae3ae/sol-astrizer`.
- Monochrome light/dark typographic wordmark assets (`assets/logo-light.svg`, `assets/logo-dark.svg`), MIT `LICENSE`, and `.gitignore`.
